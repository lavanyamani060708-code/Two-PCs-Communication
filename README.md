# Two PCs Communication Using Cisco Packet Tracer

## Aim
To establish communication between two computers using Cisco Packet Tracer and verify the connection using the ping command.

## Software Required
- Cisco Packet Tracer

## Devices Used
- 2 PCs
- 1 network connection using a suitable Ethernet cable

## IP Address Configuration

| Device | IP Address | Subnet Mask |
|---|---|---|
| PC0 | 192.168.1.1 | 255.255.255.0 |
| PC1 | 192.168.1.2 | 255.255.255.0 |

## Procedure
1. Open Cisco Packet Tracer.
2. Place two PCs in the workspace.
3. Connect the PCs using a suitable Ethernet cable.
4. Configure the IP addresses and subnet masks.
5. Open the Command Prompt on PC0.
6. Enter `ping 192.168.1.2` to test communication with PC1.

## Result
Communication between the two PCs was tested using the ping command.
